# Trading_Stock_02_Python-Release

한투 자동매매봇 **배포(릴리스) 전용** 저장소입니다.
> ⚠️ 이 저장소에는 소스코드를 올리지 않습니다.
> 
## 내려받기
[Releases](../../releases) 에서 최신 버전의 `hantoo1_vX.X.X.exe` 를 받으세요.

## 실행
1. exe 와 같은 폴더에 `.env.example` 을 `.env` 로 복사하고 KIS API 키를 입력합니다.
   (키가 없으면 시뮬레이션 모드로 동작)
2. `hantoo1_vX.X.X.exe` 실행 → 브라우저가 자동으로 열립니다.
3. 콘솔창은 켜둔 채로 사용하고, 종료는 콘솔에서 `Ctrl + C`.

자세한 사용법은 `사용법.txt` 참고.
