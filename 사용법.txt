============================================================
 한투 자동매매봇 (hantoo1) - 배포판 사용법
============================================================

[1] 준비
  1) 이 폴더(.exe 가 있는 곳)에 '.env.example' 을 복사해서
     이름을 '.env' 로 바꾸세요.
  2) .env 파일을 메모장으로 열어 아래 값을 채웁니다.
       KIS_MODE=mock              (모의투자: mock / 실전투자: real)
       KIS_APP_KEY=...            (KIS Developers 발급)
       KIS_APP_SECRET=...
       KIS_ACCOUNT_NO=12345678-01 (계좌 8자리-상품코드 2자리)
     * 키를 비워두면 '시뮬레이션 모드'로 동작해 화면만 미리 볼 수 있습니다.

[2] 실행
  - hantoo1_vX.X.X.exe 를 더블클릭하면 대시보드 서버가 시작됩니다.
  - PC 브라우저:  http://localhost:8089
  - 폰(안드로이드): PC와 같은 와이파이 연결 후,
      PC에서 명령프롬프트 'ipconfig' 로 IPv4 주소 확인 →
      폰 브라우저에서  http://(PC IP주소):8089  접속

[3] 매매 시작
  - 화면의 [🤖 AI 매매 시작] : 거래시간(한국/미국)에 맞춰 시장·종목·전략 자동 선정
  - 콤보박스에서 직접 고른 뒤 [▶ 선택값으로 시작] 도 가능
  - [■ 정지] 로 중단

[4] 결과/로그 위치 (exe 와 같은 폴더에 자동 생성)
  - debuglog\hanto_log_YYYYMMDD.log   : 실행 로그
  - result\hantoo_result.csv          : 매매 누적 결과(용량 초과 시 날짜별 백업)

[5] 업데이트
  - 화면 상단 [도움말] > [업데이트 확인] 에서 최신 버전 확인/다운로드
  - (.env 에 GITHUB_OWNER 설정 필요)

[주의] 모의투자로 충분히 검증한 뒤 실전투자로 전환하세요.
       모든 투자 책임은 본인에게 있습니다.
